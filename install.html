安裝 AI 提示詞引擎

用手機相機掃描 QR Code，開啟後依下方步驟加入主畫面，就能像 APP 一樣全螢幕使用。

https://mathedu-prog.github.io/prompt-engine/
直接開啟
iPhone / iPad

用 Safari 加入主畫面

  1. 用 Safari 掃描 QR Code 並開啟網頁（Chrome 不支援加入主畫面）。
  2. 點底部工具列的 分享 圖示（方框加向上箭頭）。
  3. 往下滑，選 加入主畫面。
  4. 確認名稱後按右上角 新增，桌面就會出現 APP 圖示。
Android

用 Chrome 安裝

  1. 用 Chrome 掃描 QR Code 並開啟網頁。
  2. 點右上角 ⋮ 選單。
  3. 選 安裝應用程式（或 加到主畫面）。
  4. 按 安裝，之後從桌面或應用程式列表開啟。
電腦 Windows / Mac

用 Chrome 或 Edge 安裝

  1. 開啟網頁後，點網址列右側的 安裝 圖示。
  2. 在跳出的視窗按 安裝。
  3. 之後會以獨立視窗開啟，可釘選到工作列。

小提醒

草稿、收藏與設定只儲存在各自裝置的瀏覽器裡，不會上傳也不會跨裝置同步；清除網站資料會一併消失。更新版本發布後，重新整理或重新開啟 APP 即可使用新版。
